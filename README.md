# Harada Tracker

An interactive tool for tracking rowing metrics, dissertation progress, and web development pipelines using the **Harada Method**.

### Overview

This Harada Tracker is a performance dashboard designed to help manage goals in athletics, clinical research, data engineering, and business development. 

### Key Features

- **3x3 Strategic Matrix:** Central focus supported by 8 main lifestyle and performance pillars.
- **64 Task Checklist:** Clickable tasks for detailed operational tracking.
- **Progress Saving:** Uses the browser's localStorage to keep track of user progress without needing a backend.
- **Responsive Design:** Built with custom CSS for both desktop and mobile use.

### Application Areas (2026–2027)

This dashboard is set up for four main workloads:

1. **NCAA Division 1 Athletics:** Aims for a sub-7:30 2K erg time for lightweight women's crew.
2. **Wet-Lab Research:** Tracks collagen degradation under acidic conditions.
3. **Bioinformatics:** Monitors Python data parsing and visualisation efforts.
4. **Digital Development:** Helps in building MVPs and business frameworks.

### How to Run Locally

1. Clone this repository: `git clone https://github.com/[YOUR-USERNAME]/harada-matrix-tracker.git`
2. Open the folder and launch `harada_tracker.html` in a modern web browser or use VS Code's *Live Server* extension.
